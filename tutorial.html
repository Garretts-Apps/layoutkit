Tutorial

LayoutKit arranges native HTML. The examples keep headings, links, buttons, lists, and landmarks as real elements. Nothing here is opened or measured by a script. lk-center covers its parent unless you set overlay="off".
Step 1

Center content

Use lk-center as a wrapper around meaningful content.

<lk-center>
  <section aria-labelledby="empty-heading">
    <h2 id="empty-heading">No results</h2>
  </section>
</lk-center>

Step 2

Stack with consistent spacing

lk-stack is a vertical flex column; gap sets the rhythm.

<lk-stack gap="md">
  <p>Summary</p>
  <p>Details</p>
</lk-stack>

Step 3

A header with lk-spread

Push children to opposite ends — logo left, links right.

<lk-spread align="center">
  <a href="/">Logo</a>
  <nav aria-label="Primary">
    <lk-row gap="sm"><a href="/">Home</a><a href="/docs">Docs</a></lk-row>
  </nav>
</lk-spread>

Step 4

A responsive grid

responsive is auto-fit. Tracks come from the available width, not a viewport breakpoint. Resize the window.

<lk-grid responsive gap="md" style="--lk-min-child-width: 140px">
  <article><h3>Project</h3></article> …
</lk-grid>

Step 5

Compose a page

fill grows a layout wrapper that is itself a flex item. The landmark stays a native main inside that wrapper.

<lk-stack style="height: 200px">
  <header><lk-spread padding="sm"><a href="/">App</a><button type="button">Menu</button></lk-spread></header>
  <lk-box fill><main><lk-center overlay="off"><h2>Content</h2></lk-center></main></lk-box>
</lk-stack>
