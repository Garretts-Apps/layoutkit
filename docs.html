Reference · 2.1.0

LayoutKit docs

A pure-CSS layout vocabulary, 80,010 bytes. lk-* tags make layout intent visible. Native HTML carries the meaning. 2.1.0 adds opt-in tags and does not change the 2.0 defaults. Types ship in jsx.d.ts.

Coming from 1.5? MIGRATION.md lists every default that changed, including the restore snippet. The path in the repo is packages/layoutkit/MIGRATION.md.

Install and load CSS

Load LayoutKit in the document head, or import it from the root of a framework. If the file does not load, the tags render as plain unknown elements and no script fills in. 2.1.0 is not on the public registry yet, so link a local copy of this build instead of a package CDN.

Scope

Stack, row, center, spread, grid, box, card, cluster, switcher, sidebar, cover, frame, bleed, spacer, divider, aspect ratio, scroll area, progress, popover, disclosure, menu, dock, select, and columns. Switcher, sidebar, and grid query their own size. Subgrid, row snap, sticky regions, anchors, and the 2.1 tags stay opt-in.

Non-goals

No button kit, form theme, icon set, or JavaScript behavior. lk-select styles a native select only where appearance: base-select exists. --lk-base does not paint until you use it. lk-card, lk-text, and lk-weight stay small helpers.

Semantic HTML first

LayoutKit is semantic to the person reading the markup, not to the accessibility tree. Do not replace main, nav, section, article, headings, buttons, links, lists, tables, or form controls.

Attributes

Attributes name stable layout behavior. They are not a mirror of every CSS property.

Spacing

gap, padding, col-gap, and row-gap take none, px, xs through 3xl, and the numeric scale. Named steps are fluid unless you set --space-*.

Alignment

align, justify, place, place-items, and center. place and justify still win over single-child centering.

Sizing

fill, full-height, width, size, min, and max-h. A boolean full-height and a plain cover use 100dvh, then 100svh, then 100vh. full-height="container" uses the query container.

Grid tracks

responsive and min are auto-fit, so empty tracks collapse. min overrides responsive. Both clamp a track to the container. flow on a grid is row, col, or dense. On a box or card it is the spacing scale.

Switcher

Omitted at, or at="md", stacks below 30rem. xs 20rem, sm 24rem, lg 40rem, xl 48rem, 2xl 64rem. at="flex" restores the --lk-switch-at formula. limit is 2–6 or off.

On by default

Container queries, single-child centering, center overlay, a switcher limit of 4, fluid space, and horizontal snap. Turn one off with container="off", adapt="off", overlay="off", limit="off", or snap="off". Subgrid, sticky, anchor, and reveal stay opt-in.

Live layouts

These regions are the stylesheet. Resize the window. A browser without a feature keeps the previous layout, because each one is wrapped in @supports.

You do not set container to turn this on. container="sm", md, lg, and xl still choose 24rem, 32rem, 48rem, and 64rem for a fixed grid. The narrow frame is 16rem, so the columns stack. The wide frame uses this column.

Frozen helpers

lk-card, lk-text, and lk-weight stay small on purpose. 2.1.0 adds opt-in look="panel", pattern, blend, bands, and lk-dock. They do nothing until you set them.

Accessibility

  • LayoutKit wraps and arranges semantic HTML. It does not replace it.
  • Do not put click handlers on lk-* elements. Use button or a.
  • Do not use lk-* elements as headings, lists, tables, forms, landmarks, or controls.
  • If a wrapper has no semantic purpose, it usually needs no ARIA. Do not add a role to make it seem semantic.
  • Focus order follows source order. The switcher does not flip flex-direction when it stacks.
  • lk-scroll-area does not create a tab stop. Set tabindex="0" and a name when the region itself must scroll from the keyboard. Without direction, both axes scroll. direction="vertical" clips inline overflow.
  • lk-menu and lk-disclosure do not invent buttons. The invoker is the first child and must be a button, link, or summary.
  • lk-progress is decorative. It does not replace a status message.
  • Reveal and disclosure motion are disabled under prefers-reduced-motion. Scroll buttons, where the browser provides them, do not replace keyboard scrolling.

TSX and JSX

jsx.d.ts teaches TypeScript the known tags and the attributes each one implements. Importing the stylesheet picks up those types. A triple-slash reference works when you do not want compilerOptions.types to replace the automatic @types list.

Browser support

Current Chrome, Firefox, and Safari cover flex, grid, cascade layers, logical properties, aspect-ratio, and min(). Viewport units step through 100dvh, 100svh, and 100vh. Dividers use color-mix() and fall back to #e5e7eb. A card border uses color-mix() and does not have that second color.

Container queries, :has(), subgrid, scroll snap, and sticky positioning are in current major browsers and still inside @supports. Anchor positioning and scroll timelines are not universal. As of November 2026, interpolate-size: allow-keywords is Chromium only among stable engines, and appearance: base-select is Chromium and Safari 27, not Firefox stable. Where the test fails, a disclosure still opens and a select stays the operating-system control.

Security

No runtime JavaScript, no dependencies, no install scripts, no remote imports, and no network requests from the stylesheet.
