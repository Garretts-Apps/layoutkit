One stylesheet · zero runtime

Pure-CSS layout primitives that replace JavaScript for layout.

LayoutKit is a readable vocabulary of lk-* wrappers — stack, switcher, sidebar, grid, and snap scrolling — used inside real HTML landmarks. Version 2.0 measures those layouts from their own container. Version 2.1 adds opt-in tags and does not change those defaults.

A vocabulary, not a framework.

What it is

One CSS file of layout primitives, 80,010 bytes (12,795 gzipped). No runtime, no dependencies, no custom-element registration. Rules live in @layer layoutkit, so an unlayered rule you write later wins.

What it is not

Not a component library, design system, or a substitute for semantic HTML. Not a button kit, form kit, theme, icon set, or JavaScript app shell. Not a utility class for every property.

Version 2.0.0

Defaults that used to be opt-in.

Tags, attribute names, and the export path are unchanged. The measurements are not. Read MIGRATION.md before upgrading. The file in the repo is packages/layoutkit/MIGRATION.md.

Container queries

lk-switcher, lk-sidebar, and lk-grid set container-type: inline-size. A switcher stacks below 30rem. A grid with fixed cols stacks below 32rem. responsive and min stay auto-fit. Opt out with container="off".

Fluid spacing

Named gaps resolve through --lk-space-*, which is var(--space-*, var(--lk-space-fluid-*)). A host --space-* token still wins. --lk-space-static-* keeps the old rem steps.

Snap scrolling

lk-scroll-area direction="horizontal" snaps its children unless snap="off". Vertical snapping still requires snap. The region needs tabindex="0" and a name when it must be a keyboard stop.

Center, overlay, limit

One child in a row or stack is centered unless adapt="off". lk-center covers a positioned parent unless overlay="off". Five or more switcher children each take a row. The default limit is 4.

width="xl" is 56rem.

The previous 64rem step is width="2xl". width="3xl" is 80rem. This page is an lk-box at 3xl. Widen the window to see the steps.

Install

Load the stylesheet early.

2.1.0 is not published yet, so the public registry still serves 1.x. Use the file in this repository, or pin the package version when you install. This site loads /layoutkit.css from the 2.1.0 build. If that file does not load, nothing in JavaScript rebuilds the layout.

Wrappers around real HTML.

Browsers do not treat lk-* tags as landmarks, headings, or controls. Keep those elements native.

Accessibility stays in the HTML.

Use a button or an a for actions. Do not put click handlers on lk-* elements.

Do not add ARIA roles to make a layout wrapper seem semantic. If it has no role, it usually needs no ARIA.

Focus order follows source order. The switcher does not reverse flex-direction when it stacks. Scroll regions that must be keyboard stops need tabindex="0" and a name.

Reveal and disclosure motion turn off under reduced motion. The content stays visible, and scroll buttons never replace the keyboard.
