Install LayoutKit

Load one CSS file early, when it controls the first paint. There is no JavaScript fallback.

npm

Pin the version. Import the stylesheet once, at the application root or in your global CSS.

Browser

2.0.0 is not on the npm registry yet, so a public package URL would still serve 1.x. Link the stylesheet shipped with this site, or copy packages/layoutkit/layoutkit.css from the repository. The copy at the site root is that same 2.0.0 build.

Download layoutkit.css

Loading

Put the link or the import where it applies before first paint. Do not lazy-load it with script if it lays out the page.

If the CSS does not load, lk-* tags are unknown elements with no layout styling. That is intentional.

What 2.0.0 changes

Container queries on switcher, sidebar, and grid, a switcher limit of 4, single-child centering, center overlay, fluid spacing, and horizontal scroll-snap are on by default. Each one has an off value.

width="xl" is 56rem. The old 64rem step is width="2xl". width="3xl" is 80rem.
